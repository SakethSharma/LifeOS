How to set up Ollama
  1. Install Ollama from ollama.com/download.
  2. Start Ollama (open the app, or run ollama serve).
  3. Download a model, for example: ollama pull llama3.2
  4. Check it's installed: ollama list
  5. Here, tap Set Up Ollama, keep {{ ollamaDefaultUrl }}, tap Test Connection, choose the model and Save.

ChatGPT is OpenAI's chat app. Its subscriptions (Go, Plus, Pro) don't include API access, and OpenAI doesn't offer a way for apps like LifeOS to use a ChatGPT subscription. ("Sign in with ChatGPT" is limited to a few approved partner apps.) To use OpenAI models here, add an OpenAI API key above — it's billed separately from ChatGPT.

LifeOS will never ask for your ChatGPT password, cookies or session tokens.
